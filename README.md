# TrashCan - Marine Debris Detection

## Project Overview

Deep Learning and MLOps project for underwater
marine debris detection using the TrashCan dataset.

## Objectives

- Analyze underwater images.
- Detect and segment marine debris.
- Train a Deep Learning model.
- Track experiments using MLflow.
- Version datasets using DVC.
- Deploy the model using FastAPI and Docker.

## Technologies

- Python
- PyTorch
- YOLO
- Git and GitHub
- DVC
- MLflow
- ONNX Runtime
- FastAPI
- React
- Docker
